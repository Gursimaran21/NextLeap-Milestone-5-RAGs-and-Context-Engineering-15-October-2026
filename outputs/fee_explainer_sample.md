# Exit Load — Explained

1. Exit load is a fee some mutual fund schemes charge when you redeem units before a defined holding period.
2. It is charged by the fund scheme, not by Groww, and is deducted from your redemption proceeds.
3. It is calculated as a percentage of the redeemed value, so the credited amount can be lower than the value shown.
4. Each scheme sets its own exit load and holding period; check the scheme's Scheme Information Document.
5. For most equity schemes the holding period is 1 year, but this varies by scheme.
6. There is no exit load after the holding period defined by the scheme.
