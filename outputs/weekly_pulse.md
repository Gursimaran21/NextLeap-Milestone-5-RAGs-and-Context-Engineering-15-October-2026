**3. Key Observation**
Charges & Fees is the dominant and rising signal, not a one-off — the same complaint recurs across weeks: the redeem/sell screen shows a gross value, the credited value is lower, and the reason is not surfaced in the flow. Payments & SIP is the second signal, with users reporting failures without an actionable reason.

**4. 3 Action Ideas**
1. Add an inline "expected exit load" line to the redeem confirmation screen.
2. Return a specific failure reason + one-tap auto-retry for failed SIP debits.
3. Add a KYC status tracker with the exact pending document and an ETA.
